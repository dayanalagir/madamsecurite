# Решения по умолчанию

Каждое решение, принятое без вопроса Даяне, записывается сюда с причиной. Вопросы с ⚑ задаются отдельно.

## Этап 0

| # | Решение | Причина |
| --- | --- | --- |
| 1 | **Почта:** SMTP Gmail, адрес `securite.editorial@gmail.com` и как отправитель, и как получатель, вход по паролю приложения. | Ответ Даяны на вопрос ⚑ из раздела 14. |
| 2 | **Два независимых потока писем:** `madam` (международная повестка) и `space` (космос). У каждого своё утреннее письмо, своя тема письма и своя идемпотентность (`digests` уникален по типу, потоку и периоду). | Просьба Даяны: «новости космические отдельно, международные для Мадам Секьюрите отдельно». |
| 3 | Топик `space` целиком в потоке `space`; остальные девять в `madam`. | Космос — отдельная экспертиза и отдельные источники (SpaceNews, Breaking Defense, Payload). |
| 4 | Расписание потока `space`: бриф в будни 07:30, короткий в выходные 09:30, тематический дайджест по вторникам 16:00, недельный обзор в воскресенье 18:30. Сдвиг на 30 минут от писем Мадам. | Чтобы два письма не приходили одновременно; вторник в ротации ТЗ и так был днём космоса, он переехал в поток `space`. |
| 5 | Пятничная сводка остаётся одним письмом Мадам, но берёт сюжеты из обоих потоков. | Карусель — продукт журнала Мадам, а космическая безопасность — флагман экспертизы автора и годится в неё. |
| 6 | Проект живёт в папке `madam-digest/` текущего репозитория `madamsecurite`, а не в отдельном репозитории. | Репозиторий для сессии уже есть; рядом лежит ТЗ и веб-дайджест. Вынести в отдельный репозиторий можно в любой момент без правок кода. |
| 7 | CLI на `argparse` из стандартной библиотеки. | Меньше зависимостей; команд немного. |
| 8 | Сборка пакета `hatchling`, установка `pip install -e ".[dev]"`. Зависимости этапа 0: `pydantic`, `pyyaml`, `python-dotenv`; `httpx`, `anthropic` и прочие добавятся на своих этапах. | Не тянуть то, что ещё не используется. |
| 9 | Конфиги проверяются `pydantic` со строгими схемами и перекрёстными ссылками (топик ↔ источник ↔ поток). Опечатка в YAML валит `madam config check` и CI. | Ошибка в конфиге должна быть видна до запуска, а не в пустом письме. |
| 10 | `config/sources.yaml` пока пустой. | Правило ТЗ: адрес попадает в конфиг только после живой проверки (этап 1). |
| 11 | Якоря и глоссарий скопированы из ТЗ как есть; у всех якорей `verified_on: null`. | Дата без проверки в письмо не попадает (раздел 10); проверка на этапе 4–5. |
| 12 | В схему добавлены поля `stream` (sources, articles, stories, digests, events_calendar) и таблица `schema_version`. | Нужны для двух потоков и будущих миграций. |
| 13 | В `.env.example` добавлены `MONTHLY_BUDGET_USD=60` и `DB_PATH`. | Месячный бюджет упомянут в разделе 18, но не было переменной; путь к базе нужен для тестов и Actions. |
| 14 | CI в `.github/workflows/madam-digest.yml` (корень репозитория), запускается только при изменениях в `madam-digest/`, на Python 3.12. | GitHub читает workflow только из корня; локально проверено также на 3.12. |
