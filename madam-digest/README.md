# madam-digest

Личный агрегатор новостей и дайджестов Madam Securité. Собирает новости и аналитику по десяти направлениям, отбирает важное, пишет по-русски короткие дайджесты и присылает их на `securite.editorial@gmail.com` по расписанию.

Письма идут двумя отдельными потоками:

| Поток | Что внутри | Тема письма |
| --- | --- | --- |
| `madam` | международная повестка: контроль над вооружениями, регионы, ООН, женщины в дипломатии, теория, технологии, карьера, язык, культура | `Мадам · Утренний бриф · 3 ноября 2026` |
| `space` | космос и космическая безопасность: SpaceNews, Breaking Defense, Payload и другие | `Мадам · Космос · Космический бриф · 3 ноября 2026` |

Полное техническое задание: [`../madam-digest-prompt.md`](../madam-digest-prompt.md). Решения, принятые по умолчанию: [`DECISIONS.md`](DECISIONS.md).

## Статус

**Этап 0 (каркас) готов.** Работают `madam config check`, `madam db init`, `madam mail status`. Остальные команды пока отвечают, на каком этапе появятся.

| Этап | Что | Статус |
| --- | --- | --- |
| 0 | Каркас, конфиги, схема базы, CI | ✅ |
| 1 | Сбор: 40+ проверенных источников | следующий |
| 2 | Анализ и утренние брифы обоих потоков | |
| 3 | Расписание и пятничная сводка (выпуск №1: черновик 5 ноября 2026) | |
| 4 | Тематические дайджесты и недельный обзор | |
| 5 | Трекеры договоров и алерты | |
| 6 | Вкус и обратная связь | |
| 7 | Ужесточение и инструкция | |

## Установка

Нужен Python 3.12 или новее.

```bash
cd madam-digest
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
```

Проверка:

```bash
madam --help
madam config check
madam db init
pytest
ruff check .
```

## Почта: Gmail securite.editorial@gmail.com

Письма уходят с этого адреса на этот же адрес через SMTP Gmail. Обычный пароль от почты не подходит, нужен **пароль приложения**:

1. Войдите в `securite.editorial@gmail.com` и включите двухэтапную аутентификацию: Аккаунт Google → Безопасность → Двухэтапная аутентификация.
2. Откройте страницу паролей приложений: Аккаунт Google → Безопасность → Пароли приложений (или по адресу `myaccount.google.com/apppasswords`).
3. Создайте пароль с названием `madam-digest`. Google покажет 16 символов.
4. Вставьте их в `.env` в строку `SMTP_APP_PASSWORD=` (пробелы можно оставить, программа их уберёт).
5. Проверьте: `madam mail status` должен написать «Пароль приложения: задан».

Пароль никогда не коммитится в репозиторий. Для запуска по расписанию на GitHub его нужно положить в секреты репозитория (Settings → Secrets and variables → Actions → `SMTP_APP_PASSWORD`). Это понадобится на этапе 3.

Отозвать доступ можно в любой момент на той же странице паролей приложений.

## Как устроено

```
config/      бренд, топики, источники, расписание, глоссарий, якоря, категории, форматы
inputs/      файлы, которые ведёт Даяна: феллоушипы, прогнозы, ручные ссылки
prompts/     промпты для модели (аналитик, триаж, пятничная сводка, идеи, проверка стиля)
sql/         схема SQLite
src/madam_digest/  код: cli, config, db, settings и модули будущих этапов
sources/     SOURCES_STATUS.md — результаты живой проверки источников (этап 1)
templates/   шаблоны писем (этап 2)
tests/       pytest
```

Топик относится к потоку через поле `stream` в `config/topics.yaml`. Чтобы перенести тему из одного потока в другой, поменяйте это поле и список `topics` у потока в `config/schedule.yaml`; `madam config check` проверит, что они совпадают.
